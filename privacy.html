1. Purpose and operator

This site describes a Google OAuth client configured for personal use with the independently maintained, open-source Obsidian GSync plugin. This site does not represent an official service by Obsidian, Google, or GSync's author. Contact: YOUR_EMAIL@example.com (replace before publishing).

2. Google data accessed

With the user's consent, GSync requests the https://www.googleapis.com/auth/drive scope, which can grant access to the user's Google Drive files. The plugin uses this permission to locate and synchronize files in the Google Drive folder selected in its settings, including reading, creating, updating and moving deleted files to trash.

3. How data is used and shared

Synced files are transferred by the plugin between the user's device and the Google Drive API. This OAuth configuration does not operate its own backend, advertising service, analytics service, or sell Google user data. Google processes data as the Drive provider. During sign-in, a static callback page may receive a one-time OAuth authorization code in its URL and pass it to the locally installed Obsidian application. The static hosting provider may process standard access logs under its own policies.

4. Storage and retention

GSync keeps OAuth client information and refresh tokens locally on each device in the Obsidian plugin settings, including .obsidian/plugins/gsync/data.json. Synced notes are stored on the user's device and in the selected Google Drive location. This website itself does not store synced note content or operate a token database. Google Drive content remains until the user changes or deletes it, subject to Google Drive's retention policies.

5. Security

The OAuth callback is delivered using HTTPS. The callback page uses client-side logic to forward sign-in information to Obsidian. The user should protect local Obsidian data, keep credentials private and only use trusted devices. Google Drive access tokens can grant broad access and must not be shared.

6. User controls and revocation

The user can stop using the plugin, delete synchronized notes, and revoke this app's Google access at Google Account permissions. Local token records can be cleared in Obsidian's plugin settings. Revoking authorization does not automatically delete Google Drive content.

7. Changes and questions

This policy will be updated if the configuration's data processing behavior changes. For questions, contact YOUR_EMAIL@example.com.
